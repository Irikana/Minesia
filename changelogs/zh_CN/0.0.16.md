# 0.0.16

## 2026.5.8

***

### 新增内容

- 添加了灵动视效（Vibrant Visuals）支持，通过色彩分级配置实现暖色调、高对比度的视觉风格，自定义物品具有微弱金属质感

### 优化改进

- 大幅下调了维克多（装备商）的金币交易价格，所有金币购买的商品价格至少减半：
  - 烈焰剑：20金币 → 8金币
  - 末影珍珠剑：25金币 → 10金币
  - 森林之剑：20金币 → 8金币
  - 凛冬之剑：10金币 → 4金币
  - 先驱者：10金币 → 4金币
  - 自私之剑：10金币 → 4金币
  - 雕像图腾：15金币 → 6金币
  - 沙漠镰刀：10金币 → 4金币
  - 生命之石：5钻石币 → 2钻石币
  - 黑色匕首：15石币 → 8石币
  - 白金剑：25石币 → 12石币

- 调整了铜制装备的数值，使其比石制装备更好、比铁制装备更弱：
  - 铜匕首伤害：2~4 → 3~5
  - 铜镰刀伤害：5.5~6.5 → 6~7.5
  - 铜匕首耐久：64 → 150
  - 铜镰刀耐久：130 → 280
