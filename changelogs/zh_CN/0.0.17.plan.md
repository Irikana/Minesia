# 0.0.17

## 2026.xx.xx

***

### 新增内容

- 新增深蓝（darkblue）全套装备：深蓝矿石（含深板岩变体，主世界地下生成）、深蓝锭、深蓝块、深蓝剑（7~9 伤害）、深蓝长矛（4~6 伤害，含原版长矛持握动画）、深蓝镐/斧/锹/锄（耐久 1800）、深蓝头盔/胸甲/护腿/靴子（防御介于钻石与下界合金），全套集齐效果 +4 生命值 +50% 体力值
- 新增武器「力量的证明」：攻击时额外造成 (当前体力 / 最大体力) × 10 点物理伤害，维克多以 3 金币出售
- 新增武器「树叶之神」：树叶飞向目标，0.5 秒内造成 3 段 1~3 点物理伤害，冷却 2 秒，可用树叶合成
- 新增武器「霜刃」：+7~10 伤害，+10% 暴击率，攻击时 35% 概率使目标缓慢 II 持续 4 秒，维克多以 2 金币、武器匠以 4 金币出售
- 新增饰品「班戈之盾」：+20 最大体力、+10% 暴击率、+25% 暴击伤害，副手时免疫弹射物伤害，维克多以 40 银币出售
- 新增武器匠村民贸易：霜刃（4 金币，限购 4 次）
- 属性面板新增设置页面，支持通过下拉菜单切换语言
- 新增共享语言管理模块（`scripts/language.js`），统一管理语言偏好
- 新增自定义 HUD 系统：通过 JSON UI 实现创世等级经验条和体力条图片化显示，完全解放 actionbar
- 新增 HUD 桥接模块（`scripts/hud_bridge/`），通过 title 通道编码数据，使用 3 个独立 data_control（dataL/dataE/dataS）分别捕获等级、经验百分比、体力百分比数据，进度条使用 `#size_binding_x` + `clips_children` 面板裁剪方案

### 优化改进

- 随机伤害系统改为只取整数（四舍五入），消除 .5 小数伤害
- 武器副手效果（烈焰剑、末影珍珠剑）改为仅副手生效，不再在背包第一行饰品栏生效
- 删除自定义 NPC（维克多、莱曼）所有限购限制，改为无限购买
- 武器匠村民降价：沙漠镰刀 25 金币 → 6 金币
- 8 把可合成镰刀配方统一改为新形状
- 10 把武器数值 / 事件调整：
  - 沙漠行者：伤害 4~7 → 5~8，缓慢时长 1 秒 → 3 秒
  - 沙漠暴雪：伤害 4~7 → 5~9
  - 烈焰剑：伤害 4~7 → 5~8，副手着火 2 秒 → 5 秒
  - 森林之剑：中毒 3 秒 → 6 秒，体力恢复 2 → 5
  - 末影珍珠剑：伤害 5~7 → 5~8
  - 凛冬之剑：伤害 5~8 → 6~9，耐久 280 → 691，效果 10 秒 → 5 秒
  - 白金剑：伤害 7~9 → 4~7，重写为 50% 概率 0.5 秒内造成 2 段 1~2 额外伤害
  - 缇娜：伤害 8~13 → 10~15，耐久 2000 → 1984
  - 黑色匕首：重写为每 3 次攻击必暴击 1 次，30% 概率使目标凋零 II 持续 6 秒
- 扩展暴击系统：新增装备暴击伤害加成接口，属性面板显示实际暴击伤害倍率
- 统一纹理子目录命名以符合原版示例包规范：`block` → `blocks`、`entities` → `entity`；清理无用的 copper_spear 纹理
- 语言系统从计分板存储迁移至 DynamicProperty，更轻量可靠
- 升级 @minecraft/server 从 2.6.0 至 2.9.0，@minecraft/server-ui 从 2.0.0 至 2.1.0
- 创世等级和体力条从 actionbar 文字进度条迁移至 JSON UI 自定义图片进度条（顶部居中，经验条在上体力条在下）
- 升级提示从 actionbar 临时覆盖改为聊天消息，避免与 HUD 通道冲突
- 等级体力加成独立存储于 `levelStaminaBonus`，与装备 / 套装加成分离，互不覆盖

### 修复

- 修复伤害显示不正确的问题：伤害显示系统与随机伤害系统都订阅 `entityHurt`，触发顺序不保证。改为延迟 1 tick 读取 `randomDamage` record 中的 `totalDamage`（已包含原版 + 随机 + 暴击），确保显示总伤害与实际造成的伤害一致
- 修复重新进入世界后体力值在世界加载期间自动恢复的问题：`handlePlayerSpawn` 显式读取 DynamicProperty 恢复体力值，设置 `spawnGraceTicks` 恢复冷却期，玩家实际移动后才清除冷却并开始恢复
- 修复等级体力加成被套装系统覆盖的问题：等级加成独立存储为 `levelStaminaBonus`，套装系统的 `clearStates` 不再影响等级加成
- 修复套装体力加成被覆盖导致体力「几乎不消耗」的问题：`setMaxStaminaBonus` 改为简单 setter 不再同步体力，避免 `clearStates` 每 3 tick 覆盖
- 修复创造模式下 actionbar 体力条仍显示并可消耗体力的问题：添加 GameMode 检查，创造 / 旁观模式下不消耗 / 恢复体力，移除体力行后清空 actionbar
- 修复 HUD 进度条静态不填充的问题：改用 3 个独立 data_control（dataL/dataE/dataS）分别捕获数据，每个使用唯一前缀避免 JSON UI 字符串减法多值解析失败
