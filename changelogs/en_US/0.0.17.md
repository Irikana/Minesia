# 0.0.17

## 2026.xx.xx

***

### New Content

- Added Darkblue full equipment set: Darkblue Ore (with deepslate variant, generates underground in Overworld), Darkblue Ingot, Darkblue Block, Darkblue Sword (7~9 damage), Darkblue Spear (4~6 damage, includes vanilla spear holding animations), Darkblue Pickaxe/Axe/Shovel/Hoe (1800 durability), Darkblue Helmet/Chestplate/Leggings/Boots (defense between diamond and netherite), full set bonus +4 Health +50% Stamina
- Added weapon "Proof of Strength": deals extra physical damage equal to (current stamina / max stamina) × 10 on attack, sold by Victor for 3 gold coins
- Added weapon "God of Leaves": leaves fly toward target, dealing 3 stages of 1~3 physical damage within 0.5s, 2s cooldown, craftable with leaves
- Added weapon "Frost Edge": +7~10 damage, +10% critical rate, 35% chance to slow target II for 4 seconds on attack, sold by Victor for 2 gold / Weapon Smith for 4 gold
- Added accessory "Shield of Bange": +20 Max Stamina, +10% Critical Rate, +25% Critical Damage, immune to projectile damage when in offhand, sold by Victor for 40 silver coins
- Added Weapon Smith villager trade: Frost Edge (4 gold coins, max 4 uses)
- Attribute Panel added settings page with language switcher dropdown
- Added shared language management module (`scripts/language.js`) for unified language preference handling
- Added custom HUD system: JSON UI-based visual experience bar and stamina bar, fully freeing the actionbar
- Added HUD bridge module (`scripts/hud_bridge/`), encodes data via title channel using 3 independent data_controls (dataL/dataE/dataS) to capture level, exp%, and stamina% separately, progress bars use `#size_binding_x` + `clips_children` panel clipping

### Improvements

- Random damage system now uses integers only (rounded), eliminating .5 fractional damage
- Weapon offhand effects (Flamie, Ender Pearl Sword) now only active in offhand slot, no longer trigger from inventory row 1 accessory slots
- Removed all purchase limits from custom NPCs (Victor, Ryaman), now unlimited
- Weapon Smith villager price reduction: Desert Scythe 25 gold → 6 gold
- 8 craftable scythe recipes unified to new shape
- 10 weapon value / effect adjustments:
  - Desert Walker: damage 4~7 → 5~8, slow duration 1s → 3s
  - Desert Snow: damage 4~7 → 5~9
  - Flamie: damage 4~7 → 5~8, offhand fire 2s → 5s
  - The Forest: poison 3s → 6s, stamina recovery 2 → 5
  - Ender Pearl Sword: damage 5~7 → 5~8
  - Duty Ice: damage 5~8 → 6~9, durability 280 → 691, effect 10s → 5s
  - White Golden Sword: damage 7~9 → 4~7, rewritten as 50% chance for 2 stages of 1~2 extra damage within 0.5s
  - Tina: damage 8~13 → 10~15, durability 2000 → 1984
  - Black Dagger: rewritten as guaranteed critical hit every 3 attacks, 30% chance to wither target II for 6s
- Extended critical hit system: added equipment critical damage bonus interface, attribute panel displays actual critical damage multiplier
- Unified texture subdirectory naming to match vanilla example pack conventions: `block` → `blocks`, `entities` → `entity`; removed unused copper_spear textures
- Language system migrated from scoreboard storage to DynamicProperty, lighter and more reliable
- Upgraded @minecraft/server from 2.6.0 to 2.9.0, @minecraft/server-ui from 2.0.0 to 2.1.0
- Creation level and stamina bars migrated from actionbar text progress bars to JSON UI custom image progress bars (top center, exp bar above stamina bar)
- Level-up notification changed from actionbar overlay to chat message to avoid HUD channel conflicts
- Level stamina bonus stored independently as `levelStaminaBonus`, separated from equipment / set bonuses

### Fixes

- Fixed incorrect damage display: damage display system and random damage system both subscribe to `entityHurt` with no guaranteed order. Changed to delay 1 tick and read `totalDamage` from `randomDamage` record (includes vanilla + random + critical), ensuring displayed total matches actual damage
- Fixed stamina auto-recovery during world loading when re-entering: `handlePlayerSpawn` explicitly reads DynamicProperty to restore stamina, sets `spawnGraceTicks` recovery cooldown, cooldown only clears after player actually moves
- Fixed level stamina bonus being overwritten by set effect system: level bonus stored independently as `levelStaminaBonus`, set effect system's `clearStates` no longer affects it
- Fixed set stamina bonus being overwritten causing stamina to "barely consume": `setMaxStaminaBonus` changed to simple setter without syncing stamina, preventing `clearStates` from overwriting every 3 ticks
- Fixed actionbar stamina bar still showing and consuming stamina in creative mode: added GameMode checks, creative / spectator modes no longer consume / recover stamina, actionbar cleared after removing stamina line
- Fixed HUD progress bars not filling: switched to 3 independent data_controls (dataL/dataE/dataS) each with unique prefix to avoid JSON UI string subtraction multi-value parsing failure
